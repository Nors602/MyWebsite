# 🏛️ SVU Events Guide - دليل فعاليات الجامعة السورية الافتراضية

موقع إلكتروني تعريفي واستعراضي لأبرز الفعاليات والأنشطة الأكاديمية والطلابية المقامة في الجامعة السورية الافتراضية (SVU)
 مميزات الموقع

 عرض الفعاليات: استعراض ورش العمل، بطولات البرمجة، وأندية الكتاب.
 تصميم تجاوبي: يتناسب مع مختلف الشاشات (أجهزة الكمبيوتر، الهواتف الذكية).
 تصفح سريع: واجهة خفيفة وسلسة للتنقل بين الصفحات.

 التقنيات المستخدمة

 HTML5 - بناء هيكلية الصفحات.
 CSS3 - التنسيق والتصميم.
 JavaScript - التفاعلية داخل الموقع.
 GitHub Pages - استضافة الموقع ونشره.
